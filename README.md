# World Snap

Собери мир из стран. На светлом фоне одна земля и кусочки. Кладёшь силуэт на место — страна пропитывается флагом.

**Игра:** https://world-snap-two.vercel.app  
**Код:** https://github.com/Raw3hape/world-snap

204 страны. Соседи сходятся на одной сфере.

```
npm install
npm run dev
```

Локально: http://localhost:5173

Проверка:

```
npm test
npm run test:e2e
```
