# World Snap

Собери мир из стран. Глобус сначала белый. Кладёшь силуэт на место — страна пропитывается флагом.

Первый стол: восемь знакомых стран. Выбираешь одну из трёх, можно раскрасить флагом, потом ставишь на глобус.

```
npm install
npm run dev
```

Открой http://localhost:5173

Проверка:

```
npm test
npm run test:e2e
```
